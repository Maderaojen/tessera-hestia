# CLI 版本對齊紀錄

- 更新：2026-10-22
- 英文版：[cli-version-alignment.en.md](cli-version-alignment.en.md)

這份表記錄：目前程式裡每個「依賴 CLI 畫面、檔案格式或行為」的功能，是對著哪個 CLI 版本、在哪天驗證的。CLI 會自動或手動更新，更新後這些功能可能默默失效（例如 Agy 1.2.10 → 1.2.12 多了狀態列，信任卡片就不出現了）。這份表讓我們能比對「現在裝的版本」和「程式對齊的版本」，知道哪些要重驗。

**這是唯一的對照表。** 程式註解與其他文件仍會寫「在哪一版觀察到什麼」，但「目前對齊到哪一版」以這裡為準。

## 目前安裝版本

| CLI | 安裝版本 | 查詢時間 | 查詢方式 |
|---|---|---|---|
| Claude Code | 2.1.301 | 2026-10-16 | `claude --version` |
| Codex CLI | 0.163.0 | 2026-10-16 | `codex --version` |
| Agy（Gemini） | 1.3.3 | 2026-10-16 | `agy --version`（會自動更新） |
| Gemini CLI（舊版） | 未安裝 | 2026-09-27 | `gemini --version` |

Janus 帳號執行的是同一份 CLI 執行檔，只是設定目錄不同，所以不另列版本。
